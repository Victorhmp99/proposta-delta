# Proposta Comercial — Delta Soluções

Site da proposta comercial (Next.js, export estático) publicado no GitHub Pages.

- Conteúdo editável: `src/content/defaultContent.ts` (ou pelo lápis no canto da página, que grava `public/content.json` direto no repositório).
- Rodar local: `npm run dev`
- Deploy: automático a cada push na `main` (`.github/workflows`).
